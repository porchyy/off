Raspberry Pi 5 + AI MediaPipe

📌 1. ภาพรวมโปรเจกต์ (Project Overview)

OffSyn Tech คืออุปกรณ์ตรวจจับสรีระการนั่งทำงานแบบเรียลไทม์ ใช้กล้องสแกนร่างกายส่วนบน (คอ ไหล่ ลำตัว) ด้วย AI MediaPipe บน Raspberry Pi 5 หากผู้ใช้นั่งหลังค่อมหรือก้มคอนานเกินไป ระบบจะส่ง เสียงพูดเตือนภาษาไทย และ ไฟ LED สีแดง เพื่อเตือนให้ปรับท่านั่งทันที พร้อมดูข้อมูลสดบนหน้าจอเว็บได้

🔒 ปลอดภัยและเป็นส่วนตัว 100%

ภาพกล้องส่งสดแบบ P2P ในวง LAN เท่านั้น ไม่มีการส่งภาพออกนอกเน็ตและไม่บันทึกภาพลงเครื่อง

🎙️ เสียงพูดไทย AI ธรรมชาติ

เตือนด้วยเสียงพูดนุ่มนวล ชัดเจน ("กรุณาปรับท่านั่งให้หลังตรงและคลายไหล่ค่ะ") ไม่มีเสียงหุ่นยนต์

⚙️ 3. ระบบการตรวจจับและการแจ้งเตือน (How it Works)

🎯 การตั้งค่าโหมดสมดุล (Balanced Focus Mode):
  • เกณฑ์คะแนนความเสี่ยง: 65 คะแนน (คะแนนเต็ม 100, ถ้าต่ำกว่า 65 ถือว่านั่งผิดท่า)
  • นั่งผิดท่าต่อเนื่อง: 8 วินาที (เพื่อไม่ให้เตือนตอนแค่ก้มหยิบของชั่วคราว)
  • เว้นระยะเตือนซ้ำ: 45 วินาที (ไม่ส่งเสียงเตือนรัวเกินไปจนรบกวนสมาธิ)

ลำดับการเตือนเมื่อนั่งผิดท่า:

  1. นาทีที่ 0 - 5: AI ตรวจพบคะแนน < 65 และเริ่มนับเวลา
  2. ครบ 5 วินาที: ไฟ LED สีแดง (Pin 11) ติดสว่าง เตือนผู้ใช้แบบเงียบๆ
  3. ครบ 8 วินาที: ลำโพงส่งเสียงพูดไทย AI *"กรุณาปรับท่านั่งให้หลังตรงและคลายไหล่ค่ะ"*
  4. เมื่อผู้ใช้นั่งหลังตรง: คะแนนกลับมาเกิน 65 → ไฟ LED ดับลงทันที

💻 4. วิธีเข้าใช้งานหน้าเว็บ Dashboard

เปิดเบราว์เซอร์ (Chrome/Safari) บนคอมพิวเตอร์หรือมือถือที่ต่อ Wi-Fi เดียวกับ Pi แล้วเข้าไปที่:

🌐 http://10.0.2.225:3000   (หรือ http://<IP-ของ-Pi>:3000)

ฟังก์ชันบนหน้าเว็บ Dashboard:

  • หน้าจอ Live: ดูภาพสดพร้อมโครงกระดูก AI เรืองแสง (Neon Skeleton) และคะแนนสรีระแบบวินาทีต่อวินาที
  • แท็บสถิติ: ดูกราฟคะแนนเฉลี่ยย้อนหลังรายสัปดาห์ จำนวนครั้งที่นั่งผิดท่า
  • แท็บตั้งค่า: ปรับคะแนนเกณฑ์เตือน, ปรับเวลาหน่วง, และมีปุ่ม "ทดสอบการแจ้งเตือน" เพื่อลองฟังเสียง
  • ส่งออกข้อมูล: ดาวน์โหลดรายงานสรุปเป็นไฟล์ Excel (.xlsx) รายวันและรายเดือนได้

⌨️ 5. รวมคำสั่งสำคัญที่ต้องใช้ (Essential Commands)

1. คำสั่งเข้าเครื่อง Pi จาก Mac (ผ่าน Terminal)

ssh porchy@10.0.2.225
# ใส่รหัสผ่านของเครื่อง Pi แล้วกด Enter

2. คำสั่งทดสอบอุปกรณ์แต่ละชิ้น

# เข้าโฟลเดอร์โปรเจกต์
cd ~/off/raspberrypi

# 1. ทดสอบอ่านเซนเซอร์วัดแสง (Lux):
.venv/bin/python test_sensors.py

# 2. ทดสอบเสียงพูดภาษาไทยผ่านลำโพง Pi:
.venv/bin/python posture_client.py --test-sound

# 3. ทดสอบกล้อง:
.venv/bin/python posture_client.py --test-camera

# 4. ทดสอบจอ LCD:
.venv/bin/python posture_client.py --test-lcd

# 5. ทดสอบไฟ LED กะพริบ 2 ครั้ง:
.venv/bin/python posture_client.py --test-led

3. คำสั่งอัปเดตโค้ดและรีสตาร์ทระบบ

# ดึงโค้ดล่าสุดจาก GitHub:
cd ~/off
git fetch origin && git reset --hard origin/main

# รีสตาร์ทหน้าเว็บ Dashboard:
sudo docker-compose restart web

# รีสตาร์ท Service กล้องและ AI:
sudo systemctl restart postureai-client
