1. ที่มา ความสำคัญ และภาพรวมระบบ (Project Background & Overview)

โรคออฟฟิศซินโดรม (Office Syndrome) เกิดจากการนั่งทำงานผิดท่าเป็นระยะเวลานาน เช่น หลังค่อม (Slouching), ไหล่ห่อ (Rounded Shoulders), และศีรษะยื่นไปข้างหน้า (Forward Head Posture) ส่งผลให้เกิดอาการปวดกล้ามเนื้อเรื้อรังและกระดูกสันหลังผิดรูป

OffSyn Tech ได้รับการออกแบบขึ้นเพื่อเป็นระบบตรวจจับและเตือนสรีระท่านั่งแบบอัตโนมัติ 100% โดยผสานการทำงานระหว่าง Raspberry Pi 5, กล้องความเร็วสูง (Pi Camera Module 3), ปัญญาประดิษฐ์ตรวจจับโครงกระดูกมนุษย์ (Edge AI MediaPipe Pose), เซนเซอร์วัดสภาพแวดล้อม (BH1750 Lux Sensor), ระบบเสียงเตือนภาษาไทยธรรมชาติ AI และ Web Dashboard แสดงผลสดผ่าน WebRTC ในเครือข่ายภายใน

🔒 รักษาความเป็นส่วนตัว 100% (Zero Cloud Leak)

ประมวลผล AI และสตรีมภาพสดผ่าน WebRTC แบบ Peer-to-Peer ในวง LAN เท่านั้น ไม่มีการส่งภาพขึ้นคลาวด์ และไม่บันทึกภาพลงฮาร์ดดิสก์

3. แผนผังการต่อวงจรและพินฮาร์ดแวร์ฉบับสมบูรณ์ (Complete Hardware Wiring)

ตารางการต่อสายไฟของอุปกรณ์ทั้งหมดเข้ากับหัวพิน 40-Pin GPIO Header บนบอร์ด Raspberry Pi 5:

อุปกรณ์ (Device) พินบนบอร์ด (Physical Pin) รหัส BCM (GPIO) ประเภทสัญญาณ คำอธิบายการทำงาน
BH1750
(เซนเซอร์วัดแสงสว่าง Lux)		 Pin 1 3.3V Power Power ไฟเลี้ยง 3.3V
Pin 3 GPIO 2 (SDA1) I2C Data สายข้อมูล I2C (Address 0x23 หรือ 0x5C)
Pin 5 GPIO 3 (SCL1) I2C Clock สายสัญญาณนาฬิกา I2C Bus 1
Pin 6 หรือ 9 GND Ground ขั้วกราวด์
LCD 1602 (I2C)
(จอแสดงผล 16x2)		 Pin 2 หรือ 4 5V Power Power ไฟเลี้ยง 5V สำหรับบอร์ดและ Backlight
Pin 3 GPIO 2 (SDA1) I2C Data แชร์สาย I2C Data ร่วมกับ BH1750 (Address 0x27)
Pin 5 GPIO 3 (SCL1) I2C Clock แชร์สัญญาณนาฬิกา I2C Clock
Pin 6 หรือ 9 GND Ground ขั้วกราวด์
LED Indicator
(ไฟเตือนสีแดง)		 Pin 11 GPIO 17 Digital Output จ่ายไฟ 3.3V ให้ไฟติดเมื่อนั่งผิดท่าต่อเนื่องเกิน 5 วิ
Pin 9 หรือ 14 GND Ground ขั้วลบกราวด์ (ต่อผ่านตัวต้านทาน 220Ω - 330Ω)
Buzzer
(ลำโพงบี๊บฮาร์ดแวร์)		 Pin 13 GPIO 27 Digital Output ส่งสัญญาณเสียงบี๊บเตือนฉุกเฉินเมื่อคะแนนต่ำกว่า 50
Pin 14 หรือ 20 GND Ground ขั้วกราวด์
MAX98357A
(I2S DAC แอมป์เสียง)		 Pin 2 หรือ 4 5V Power Power ไฟเลี้ยง 5V สำหรับวงจรขยายเสียงลำโพง
Pin 12 GPIO 18 (PCM_CLK) I2S BCLK Bit Clock สัญญาณนาฬิกาเสียงดิจิทัล
Pin 35 GPIO 19 (PCM_FS) I2S LRCLK Left/Right Frame Clock เลือก Channel เสียง
Pin 40 GPIO 21 (PCM_DOUT) I2S DIN Digital Audio Data ข้อมูลเสียง PCM 44.1kHz

4. อัลกอริทึม AI และสูตรการคำนวณสรีระ (AI Pose Geometry & Scoring Math)

ระบบใช้ MediaPipe Pose Landmarker Full ตรวจจับพิกัด 3 มิติ (X, Y, Z, Visibility) ของจุดสำคัญ 8 จุดบนร่างกายส่วนบน โดยไม่พึ่งพาสะโพกหรือขาเพื่อป้องกันความผิดพลาดจากโต๊ะทำงานบดบัง:

1. ความเอียงไหล่ (Shoulder Tilt)

คำนวณจากมุมองศาความชันระหว่างไหล่ซ้าย (11) และไหล่ขวา (12): ยิ่งต่างระดับมาก คะแนนยิ่งลดลง

2. คอยื่น/ก้ม (Neck Incline)

วัดระยะและมุมของหู (7, 8) เทียบกับแนวดิ่งของหัวไหล่ (11, 12) เพื่อตรวจจับอาการ Forward Head

3. สมมาตรลำตัว (Torso Align)

คำนวณแกนกลางลำตัวจากกึ่งกลางไหล่ไปยังแนวกึ่งกลางอก เพื่อตรวจจับการนั่งเอียงข้างหรือบิดตัว

🎯 ตรรกะการแจ้งเตือนแบบ Balanced Focus Mode (รูปแบบที่ 1):
  • คะแนนรวมสรีระ (0 - 100): คะแนนเต็ม 100 = สรีระตั้งตรงสมบูรณ์แบบ, คะแนน ≥ 65 = ปกติ (Good Posture)
  • เกณฑ์แจ้งเตือน (Risk Threshold = 65): เมื่อคะแนนตกต่ำกว่า 65 ระบบจะระบุว่าเป็นท่านั่งเสี่ยง (Risk Posture)
  • ระยะเวลานั่งผิดท่าต่อเนื่อง (Duration = 8 วินาที): ป้องกันการแจ้งเตือนตอนก้มหยิบของ บิดขี้เกียจ หรือดื่มน้ำ
  • ระยะเว้นการเตือนซ้ำ (Cooldown = 45 วินาที): เว้นระยะไม่ให้ส่งเสียงเตือนติดกันรัวเกินไปจนรบกวนสมาธิ

5. สถาปัตยกรรมระบบเสียงและอุปกรณ์แจ้งเตือน (Audio & Actuators Architecture)

1. ระบบเสียงพูดภาษาไทยธรรมชาติ AI (Natural AI Voice Alert)

เดิมระบบใช้ espeak-ng ซึ่งเป็นเสียงสังเคราะห์หุ่นยนต์แบบเก่า ทำให้ฟังยากและเหมือนเสียงเอเลี่ยน ระบบได้รับการปรับปรุงใหม่ทั้งหมดโดยใช้ AI Neural Voice (Microsoft Edge TTS - เสียงคุณเปรมวดี) ซึ่งสังเคราะห์และแปลงเป็นไฟล์ alert_thai.wav (PCM 16-bit 44.1kHz Stereo):

  • บน Raspberry Pi 5: เล่นไฟล์ alert_thai.wav ผ่านลำโพงแอมป์ขยาย MAX98357A I2S โดยตรงด้วย ALSA aplay
  • บนหน้าเว็บ Dashboard: เล่นไฟล์ alert_thai.wav ผ่าน HTML5 Audio API บนเบราว์เซอร์ของเครื่องคอมพิวเตอร์/มือถือที่เปิดดู Dashboard อยู่
  • ตัดเสียงหุ่นยนต์ออก 100%: ลบคลาส SpeechPlayer และคำสั่ง espeak-ng ออกทั้งหมด ทำให้ไม่มีเสียงเอเลี่ยนแทรกซ้อนอีกต่อไป

2. ไฟแสดงสถานะ LED สีแดง (Pin 11 / GPIO 17)

ควบคุมผ่านไดรเวอร์ lgpio (RP1 Chip บน Pi 5) หรือ gpiozero:

  • เมื่อคะแนนตกต่ำกว่า 50 คะแนนต่อเนื่องเกิน 5 วินาที → ระบบสั่งจ่ายไฟ 3.3V (HIGH) ให้ไฟ LED สว่างขึ้นเตือนแบบเงียบๆ
  • เมื่อผู้ใช้ปรับท่านั่งกลับมาหลังตรง (คะแนน ≥ 50) → ระบบสั่งตัดไฟ 0V (LOW) ให้ไฟ LED ดับลงทันที

3. จอแสดงผล LCD 1602 (I2C Address 0x27)

แสดงผลคะแนนสรีระแบบ Real-time 2 บรรทัด เช่น:

| POSTURE: GOOD  |

6. สถาปัตยกรรมฐานข้อมูลและ RESTful API (Database & API Architecture)

ตารางฐานข้อมูล SQLite (Database Schema):

  • samples: เก็บข้อมูลผลการวัดสรีระ (คะแนน, มุมคอ, ไหล่, เวลาบันทึก) มีนโยบายล้างข้อมูลเก่าอัตโนมัติทุก 35 วัน
  • alerts: เก็บบันทึกประวัติเหตุการณ์ที่เกิดการแจ้งเตือนท่านั่งเสี่ยง
  • daily_summaries: เก็บสรุปสถิติคะแนนเฉลี่ยและจำนวนครั้งที่เตือนรายวัน เก็บไว้นาน 365 วัน สำหรับวิเคราะห์ระยะยาว
  • settings: ตาราง Key-Value เก็บค่าคอนฟิกของระบบ (Risk Threshold, Duration, Sound Enabled)

รายการ REST API Endpoints หลัก:

Method Endpoint คำอธิบายการทำงาน

POST /api/metrics Pi Client ส่งคะแนนสรีระและมุมองศาร่างกายมาบันทึกลงฐานข้อมูล

GET / PUT /api/settings อ่านและอัปเดตการตั้งค่าระบบ (ป้องกันด้วย Admin Token)
