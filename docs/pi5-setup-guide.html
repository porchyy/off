ติดตั้ง PostureAI บน Raspberry Pi 5

สำหรับ Raspberry Pi 5 (8 GB) + Raspberry Pi Camera Module: ล้างเครื่อง ลง Raspberry Pi OS และเปิดระบบตรวจท่านั่ง

คำเตือน: การเขียน Raspberry Pi OS ลง microSD จะลบข้อมูลทั้งหมดบนการ์ดใบนั้น ตรวจชื่อไดรฟ์ให้ถูกก่อนกด Write

ของที่ต้องมี

  • Raspberry Pi 5 รุ่น RAM 8 GB, microSD card (แนะนำ 32 GB ขึ้นไป) และไฟเลี้ยง
  • คอมพิวเตอร์สำหรับเขียน microSD และอินเทอร์เน็ต
  • Raspberry Pi Camera Module และสายแพ CSI ที่ต่อแน่นเรียบร้อย
  • เครือข่าย Wi-Fi หรือสาย LAN

สิ่งที่ต้องดาวน์โหลด

  1. Raspberry Pi Imager ลงบนคอมพิวเตอร์: https://www.raspberrypi.com/software/
  2. ไม่ต้องดาวน์โหลด Docker, Python, MediaPipe หรือไฟล์โมเดลเอง — สคริปต์ของโปรเจกต์จะติดตั้งให้หลังเปิด Pi แล้ว

1. สำรองข้อมูล (ถ้าต้องการ)

หากต้องเก็บฐานข้อมูลจากเครื่องเดิม ให้รันบนคอมพิวเตอร์ (แทน <IP-Pi> ด้วย IP จริง):

scp porchy@<IP-Pi>:/home/porchy/off/database/postureai.sqlite .

ถ้าไม่มีข้อมูลสำคัญ ข้ามขั้นตอนนี้ได้

2. เขียนระบบปฏิบัติการใหม่

  1. ปิด Pi แล้วถอด microSD มาเสียบคอมพิวเตอร์
  2. เปิด Raspberry Pi Imager
  3. เลือก Device: Raspberry Pi 5
  4. เลือก OS: Raspberry Pi OS (other) → Raspberry Pi OS (Legacy, 64-bit) — ตัวนี้คือ Bookworm และมี Desktop
  5. เลือก Storage: microSD ของ Pi
  6. กดไอคอนรูปเฟือง หรือ Edit Settings แล้วตั้งค่า:
    • Hostname: postureai
    • Username: porchy
    • Password: ตั้งรหัสผ่านที่จำได้
    • Configure wireless LAN: ชื่อ Wi-Fi และรหัสผ่าน
    • Enable SSH: ใช้ password authentication
    • Timezone: Asia/Bangkok
  7. กด Write และยืนยันการลบข้อมูล

3. เปิด Pi และเชื่อมต่อ

  1. นำ microSD กลับไปใส่ Pi แล้วเปิดเครื่อง
  2. รอ 1–2 นาทีให้ Pi ต่อ Wi-Fi
  3. เปิด Terminal บนคอมพิวเตอร์ แล้วเชื่อมต่อ:
ssh porchy@postureai.local

หากหาเครื่องไม่เจอ ให้ดู IP จากหน้า router แล้วใช้ ssh porchy@<IP-Pi>

4. ติดตั้งโปรเจกต์

หลัง SSH เข้า Pi สำเร็จ ให้รันทีละบรรทัด:

sudo apt update
sudo apt full-upgrade -y
sudo apt install -y git
git clone https://github.com/porchyy/off.git
cd off
chmod +x raspberrypi/setup-pi5.sh
./raspberrypi/setup-pi5.sh
คำสั่งสุดท้ายใช้เวลาหลายนาที เพราะติดตั้ง Docker, ไลบรารีกล้อง, MediaPipe, ไฟล์โมเดล และสร้างบริการให้เริ่มเองหลัง reboot

5. เปิดใช้งาน

ดู IP ของ Pi:

hostname -I

เปิดจากมือถือหรือคอมพิวเตอร์ที่อยู่ Wi-Fi เดียวกัน:

http://<IP-Pi>:3000

ตรวจสอบหากมีปัญหา

sudo systemctl status postureai-stack postureai-client
sudo journalctl -u postureai-client -f

ทดสอบกล้องและ MediaPipe:

cd ~/off/raspberrypi
.venv/bin/python posture_client.py --config config.yaml --check

สรุปสำคัญ

  • ชุดเป้าหมายของโปรเจกต์นี้คือ Raspberry Pi 5 (8 GB) + Raspberry Pi Camera Module
  • เลือก Raspberry Pi OS (Legacy, 64-bit) ซึ่งเป็น Bookworm พร้อม Desktop ไม่ใช่ Debian 13 ทั่วไป
  • ดาวน์โหลดเองแค่ Raspberry Pi Imager
  • ตั้ง Wi-Fi และ SSH ใน Imager ก่อนเขียน microSD จะสะดวกที่สุด
  • ห้ามรัน ./raspberrypi/setup-pi5.sh ด้วย sudo
